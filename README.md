# Interactive Venue Ticketing System

Web & Mobile 1 project: a seat-selection website for the Azerbaijan State Academic Russian Drama Theater Hall, built with HTML, CSS and JavaScript.

## Features
- Theater hall with 4 sections (Front Left, Front Right, Back Left, Back Right) and 224 seats generated from JavaScript data
- Two price categories: Front (20 AZN) and Back (15 AZN)
- Seat states: available, inspected, in cart, unavailable
- Click a seat to see its details and price; only ADD TO CART adds it
- Cart with ticket list, total price and remove buttons(map stays in sync)
- Duplicate seats cannot be added
- Cart saved in localStorage and restored after refresh
- Zoom in/out, move up/down/left/right and reset view buttons
- Responsive layout for small screens

## How to run
Open `index.html` in a browser. No installation is needed.
